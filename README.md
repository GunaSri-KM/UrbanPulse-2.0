# 🌆 UrbanPulse 2.0

### Real-Time Smart City Dashboard

UrbanPulse 2.0 is a modern smart-city dashboard designed to bring essential everyday city information into one clean and interactive interface.

Instead of checking different websites for time, weather, location and forecasts, UrbanPulse provides these details together in a single dashboard.

## ✨ Features

- 🕒 Real-time local time
- 📅 Current date and day
- 📍 Location detection
- 🌤️ Live weather information
- 🌡️ Current temperature
- ☁️ Weather condition
- 📊 5-day weather forecast
- 🚦 City activity / traffic section
- 📱 Responsive dashboard interface
- 🔄 Automatically updates information

## 🎯 Purpose

UrbanPulse 2.0 focuses on making everyday city information simple, accessible and easy to understand through a single web dashboard.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Geolocation API
- Weather API
- GitHub Pages
